Run Zyrox (bookmarklet)
  1. Save the bookmarklet (copy URL into a bookmark on mobile).
  2. Open gimkit.com/join, tap the bookmark before joining when possible.
  3. If load fails, Gimkit may block cross-origin fetch; use Tampermonkey with the raw script URL instead.
